# 角度探险家｜离线课堂使用说明

## 适用内容

本应用面向人教版小学四年级上册“角的度量”相关课时，围绕角的大小、度、直角/平角/周角、量角器读数和转向角度设计。机器人餐厅是课堂情境化练习，不是人民教育出版社官方数字教材。

## 打开方式

1. 解压本包，双击 `角度探险家.html`。
2. 推荐横屏 1920×1080、Chrome 或 Edge、浏览器缩放 100%，再点击应用右上角“全屏”。
3. 应用无需登录和网络；课堂记录只保留在当前浏览器页面。
4. 一体机宽度小于 900 CSS px 时，双人赛会显示窄屏提示；可切回“全班共答”。

## 课堂流程

### 1. 角度实验室

先让学生拖动活动边估角，再打开量角器核对。可切换左右基准边，比较内外两圈刻度；点顶部度数读数卡可用屏幕数字盘输入 1°—180°。

### 2. 机器人餐厅

机器人从左下角取餐口出发，初始朝右。将“直行、左转、右转、重复”积木拖入程序，完成送餐后回到取餐口并恢复朝右。循环使用 C 形语句槽，槽内动作才会重复；“接着试”会保留已验证的前缀，适合反复修改。

点击“下一条”观察单步运行，点击“看 Python 逻辑”把积木对应到 `for`、缩进和 `move()`/`turn_left()`/`turn_right()`。

### 3. 角度挑战

“全班共答”可由老师逐题停留、邀请学生说理由；“双人同屏赛”让两名学生左右分屏作答。双方都准备后统一倒数；每题按难度限时 15—35 秒，超时得 0 分。提交后立即公示正确选项和本题对错，约 1.2 秒自动进入下一题。

双方全部完成后才显示比赛结果小窗口；老师点击“查看答案解析”再进入总结，可筛选错题并展开逐题解析。绿色只代表答对，红色代表答错或超时；双方都错时两侧都应为红色。

## 触控提示

按钮和积木按触控尺寸设计。拖动积木时先按住积木主体再移动，放入 C 形槽会出现吸附高亮；底部工具栏可撤销、重做、复制、删除、缩放和平移。双人赛需要一体机支持多点触控。

## 教材与反馈

教师可从页脚“教材依据与使用说明”再次打开课堂指南。课堂中建议先观察、再估测、动手验证，最后让学生用语言说明“为什么这个转弯要用 90°/180°”。
